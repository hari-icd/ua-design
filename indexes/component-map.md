# Component Map

Fast lookup index for agents choosing UnifyApps design-system components.

## Core Components
| Component | Source | Primary role | Use first when |
|-----------|--------|--------------|----------------|
| Alerts & Notifications | [alerts-notifications.md](../components/alerts-notifications.md) | Feedback/status | User needs success, warning, error, async, or notification feedback |
| Avatar | [avatar.md](../components/avatar.md) | Identity | Representing users, collaborators, entities, or profile photos |
| Breadcrumbs | [breadcrumbs.md](../components/breadcrumbs.md) | Hierarchy context | User is 3+ levels deep and needs a path back |
| Button | [button.md](../components/button.md) | Action trigger | User triggers save, submit, delete, AI, or secondary actions |
| Button+Toggle Groups | [button-toggle-groups.md](../components/button-toggle-groups.md) | Grouped controls | Users need a compact cluster of related actions or visible peer options |
| Checkbox & Radio | [checkbox-radio.md](../components/checkbox-radio.md) | Selection | Visible boolean, multi-select, or 2–5 mutually exclusive options |
| Code Snippet | [code-snippet.md](../components/code-snippet.md) | Read-only code display | Showing copyable code, commands, config, IDs, or API output |
| Dropdowns | [dropdowns.md](../components/dropdowns.md) | Compact menu/options | Exposing compact choices, contextual actions, or overflow controls |
| Inputs | [inputs.md](../components/inputs.md) | Text entry | Collecting/editing short-form user-entered values |
| List Item Cards | [list-item-cards.md](../components/list-item-cards.md) | Rich row/card list item | Users scan records with secondary context or per-item actions |
| Loading Indicator | [loading-indicator.md](../components/loading-indicator.md) | Indeterminate loading | Async operation takes more than 300ms and content is blocked |
| Pill | [pill.md](../components/pill.md) | Metadata/status chip | Users need compact non-interactive labels or statuses |
| Scrollbar | [scrollbar.md](../components/scrollbar.md) | Overflow affordance | A constrained region needs visible overflow feedback |
| Selection Pill | [selection-pill.md](../components/selection-pill.md) | Visible compact selection | Users choose small visible filter or segment options |
| Sliders | [sliders.md](../components/sliders.md) | Bounded numeric adjustment | Users adjust a value by position on a range |
| Tabs | [tabs.md](../components/tabs.md) | Parallel navigation | Switching between 2–7 related peer sections |
| Toggles | [toggles.md](../components/toggles.md) | Binary setting | Users turn a setting on or off |

## Agent Shortcut
- For local page/section switching, check [Tabs](../components/tabs.md).
- For ordered steps, check [Progress Steps + Timeline](../application-components/progress-steps-timeline.md).
- For global movement, check [Navigation](../application-components/navigation.md).
- For action hierarchy, check [Button](../components/button.md) and [Section Footers](../application-components/section-footers.md).
- For compact grouped actions or segmented choices, check [Button+Toggle Groups](../components/button-toggle-groups.md).
- For status/feedback, check [Alerts & Notifications](../components/alerts-notifications.md).
